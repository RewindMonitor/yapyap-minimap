## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Player Markers** | All teammate positions shown as colored dots on the minimap |
| **Resource Icons** | Nearby resource nodes shown on map for efficient gathering |
| **Zoom Control** | Smooth zoom from close-range tactical to wide area overview |
| **Opacity Slider** | Adjust minimap transparency so it never blocks your view |
